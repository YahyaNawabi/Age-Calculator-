# Age-Calculator-
# 🎂 JavaScript Age Calculator

This is a simple and responsive **Age Calculator** built with HTML, CSS, and JavaScript. The user selects their date of birth, and the app calculates the exact age in years, months, and days.

## 🚀 Live Demo

👉 [Click here to try it out](https://yahyanawabi.github.io/Age-Calculator-/)

## 🧩 Features

- Input your birth date using a date picker.
- Displays age in **years, months, and days**.
- Prevents users from selecting future dates.
- Responsive and mobile-friendly design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
